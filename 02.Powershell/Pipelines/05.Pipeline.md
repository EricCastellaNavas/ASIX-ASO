# Pipeline

## 1. Primer pipeline

Executa:

```powershell
Get-Service
```

>![get-service](/02.Powershell/Pipelines/Imatges/Get-service.png)

Ara executa:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Quina diferència observes entre les dues sortides?

> Ordena de la A-Z.

2. Què fa la part situada abans de `|`?

> Ens serveix per demanar els serveis.

3. Què fa la part situada després de `|`?

> Ens ajuda a ordenar els noms dels serveis de la A-Z.

4. `Sort-Object` crea els serveis o rep serveis creats per una altra ordre?

> El que fa es ordenar els serveis ja creat previament.

5. Quina ordre és la que genera inicialment les dades?

> la comanda Get-service 

Fes ara la prova:

```powershell
Get-Service | Sort-Object Status
```

Què ha canviat?

> Ha canviat que ara ordena per si el servei s'esta exacutan o no.

Finalment:

```powershell
Get-Service | Sort-Object Status -Descending
```

> Fa el mateix pero ara els primers que s'estan executant i despres es que estan parats.

Explica amb les teves paraules què ha fet el pipeline.

> Ens permes ordenar els serveis per nom i per status.

## 3. Construir un pipeline pas a pas

Executa primer:

```powershell
Get-Process
```

Ara:

```powershell
Get-Process | Sort-Object CPU
```

Finalment:

```powershell
Get-Process |
    Sort-Object CPU |
    Select-Object -First 5
```

No continuïs fins haver observat el resultat de cada ordre.

Completa:

| Pas | Ordre | Què entra? | Què surt? |
|---|---|---|---|
| 1 | `Get-Process` | No rep dades del pipeline; consulta els processos del sistema. | Objectes amb informació dels processos en execució. |
| 2 | `Sort-Object CPU` | Els objectes retornats per `Get-Process`. | Els mateixos processos ordenats pel valor de CPU, de menor a major. |
| 3 | `Select-Object -First 5` | Els processos ordenats. | Els cinc primers processos de la llista ordenada. |

Explica què passaria si eliminéssim:

```powershell
Sort-Object CPU
```

del pipeline.

Comprova-ho executant:

```powershell
Get-Process | Select-Object -First 5
```

Els cinc processos obtinguts són necessàriament els que consumeixen més CPU?

Explica per què.

> No ja que nomes es ara mateix nomes es veurien els primer 5 resultats de cada proceses del sistema no nomes el de la cpu.

## 5. Canviar l'ordre del pipeline

Executa:

```powershell
Get-Process |
    Sort-Object CPU -Descending |
    Select-Object -First 5
```

Ara executa:

```powershell
Get-Process |
    Select-Object -First 5 |
    Sort-Object CPU -Descending
```

Respon:

1. Les dues ordres fan el mateix?

> No exactament

2. Per què?

> La primera primer ordenar i despres agafar es primer 5 la segona primer agafar els primers 5 i despres els ordena el resultat no es el mateix.

3. Quants processos arriben a `Sort-Object` en el primer cas?

> Tots els de GET-PROCESS pero ordenat 

4. Quants processos arriben a `Sort-Object` en el segon?

> Els 5 primers que ha seleccionat primer sort-object 

Aquest exercici és important: **l'ordre dels cmdlets dins del pipeline modifica el resultat**.
