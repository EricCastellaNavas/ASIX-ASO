# Treballar amb fitxers i carpetes

**Situació:** descobrir les ordres per treballar amb fitxers i carpetes utilitzant `Get-Command` i `Get-Help`, sense buscar respostes a Internet.

He fet les proves amb PowerShell 7.6.5 sobre Windows. Les captures són de les execucions reals i utilitzen rutes relatives a aquesta fitxa.

## 1. Buscar ordres

He buscat les ordres que contenen la paraula `Item`:

```powershell
Get-Command *Item*
```

El comodí `*` permet trobar noms amb qualsevol text abans o després d'`Item`. El resultat mostra el nom, el tipus d'ordre, la versió i el mòdul d'origen.

![Resultat de Get-Command amb el patró Item](./Imatges/01-buscar-ordres.png)

Entre els resultats he identificat aquestes ordres:

| Acció | Cmdlet trobat |
|---|---|
| Crear un element | `New-Item` |
| Eliminar un element | `Remove-Item` |
| Canviar el nom d'un element | `Rename-Item` |
| Copiar un element | `Copy-Item` |
| Moure un element | `Move-Item` |

També hi apareixen `Get-Item` i `Get-ChildItem`, que permeten consultar un element i llistar el contingut d'una carpeta. Encara no he executat cap ordre que modifiqui fitxers.

---

**2. Investigar una ordre**

Sense executar-la encara, consulta què fa:

```
Get-Help New-Item
```

Respon:

- Per a què serveix `New-Item`?
> serveix per crear un element nou, com ara un fitxer o una carpeta. El tipus d’element depèn del proveïdor de PowerShell on treballis.
- Quina estructura té l'ordre?

>New-Item -Path <ubicació> -Name <nom> -ItemType <tipus>

- Consulta alguns exemples:

>| Paràmetre | Funció |
>|---|---|
>| `-Path` | Indica on es crearà l’element. |
>| `-Name` | Indica el nom del nou element. |
>| `-ItemType` | Indica quin tipus d’element es crearà. |

---

**3. Descobrir un paràmetre**

Consulta què significa el paràmetre `-ItemType`:

```
Get-Help New-Item -Parameter ItemType
```
A partir de l'ajuda, intenta descobrir com crear una carpeta.

Per exemple, haurien d'arribar a alguna cosa semblant a:

```
New-Item -ItemType Directory -Name Prova
```
>Aquest paràmetre indica el tipus d’element que volem crear. Per crear una carpeta, cal utilitzar el valor Directory.

>A continuació, he creat una carpeta anomenada Prova a la ubicació actual de PowerShell:

>![creacio carpeta](/02.Powershell/Imatges/Creacio%20Carpeta.png)


---

**4. Nou repte**

Ara necessites saber com **canviar el nom de la carpeta**, però no coneixes l'ordre.

Utilitza:

```
Get-Command *Item*
```

i després consulta l'ajuda de l'ordre que creguis adequada.

L'objectiu és arribar a descobrir:

```
Rename-Item
```

i consultar:

```
Get-Help Rename-Item -Examples
```

---

Sense utilitzar Internet, descobreix quins cmdlets faries servir per:

1. crear una carpeta;
2. canviar-li el nom;
3. copiar-la;
4. moure-la;
5. eliminar-la.

**Condició:** només pots utilitzar `Get-Command` i `Get-Help` per investigar les ordres.
