# Scripts PowerShell

L'objectiu d'aquesta pràctica és integrar els conceptes treballats durant la introducció a PowerShell:

- variables;
    
- tipus de dades;
    
- arrays;
    
- pipeline;
    
- `Select-Object`;
    
- `Where-Object`;
    
- propietats dels objectes;
    
- `if`, `elseif`, `else` i `switch`;
    
- `foreach` i `ForEach-Object`;
    
- scripts `.ps1`.
    

> **Important:** abans d'incorporar una ordre al script, és recomanable provar-la directament a la consola de PowerShell.
# 1. Informació bàsica del sistema

Crea un script anomenat:

```
infoSistema.ps1
```

El script ha de mostrar:

- nom de l'equip;

- usuari actual;

- versió de PowerShell;

- data i hora actuals;

- directori actual.


La sortida ha de ser clara i llegible.

Per exemple:

```
===== INFORMACIÓ DEL SISTEMA =====

Equip: ...
Usuari: ...
PowerShell: ...
Data: ...
Directori actual: ...
```
1. Adjunta el script final.
2. Explica el procés que has seguit o operacions que has executat abans d'obtenir el script final.

### Resolució

Primer he consultat el nom de l'equip i l'usuari amb les variables d'entorn. Després he provat la versió de PowerShell, la data i el directori actual a la consola. He guardat les dades en variables i he afegit un títol i una etiqueta a cada línia perquè es llegeixi millor.

**Proves a la consola:**

```powershell
$env:COMPUTERNAME
$env:USERNAME
$PSVersionTable.PSVersion.ToString()
Get-Date -Format 'dd/MM/yyyy HH:mm:ss'
(Get-Location).Path
```

**Sortida obtinguda:**

```text
ERIC
01cas
7.6.5
19/10/2026 16:35:37
C:\Users\01cas\ASIX-ASO\Powershell\08.Scripts
```

**Script final:** [infoSistema.ps1](./infoSistema.ps1)

```powershell
#requires -Version 7.0

# Recullo les dades abans de mostrar-les.
$nomEquip = $env:COMPUTERNAME
$usuariActual = $env:USERNAME
$versioPowerShell = $PSVersionTable.PSVersion.ToString()
$dataActual = Get-Date -Format 'dd/MM/yyyy HH:mm:ss'
$directoriActual = (Get-Location).Path

Write-Output '===== INFORMACIÓ DEL SISTEMA ====='
Write-Output ''
Write-Output "Equip: $nomEquip"
Write-Output "Usuari: $usuariActual"
Write-Output "PowerShell: $versioPowerShell"
Write-Output "Data: $dataActual"
Write-Output "Directori actual: $directoriActual"
```

**Execució del script complet:**

```powershell
pwsh -NoProfile -File .\infoSistema.ps1
```

**Sortida obtinguda:**

```text
===== INFORMACIÓ DEL SISTEMA =====

Equip: ERIC
Usuari: 01cas
PowerShell: 7.6.5
Data: 19/10/2026 16:35:38
Directori actual: C:\Users\01cas\ASIX-ASO\Powershell\08.Scripts
```

He executat el script amb PowerShell 7 des de la carpeta de la pràctica. La data i el directori corresponen al moment i al lloc des d'on l'executo.

# 2. Estat dels serveis

Crea:

```
estatServeis.ps1
```

El script ha de:

1. obtenir tots els serveis del sistema;

2. comptar quants estan en execució;

3. comptar quants no estan en execució;

4. mostrar el total de serveis;

5. mostrar els resultats al final.


Exemple:

```
===== ESTAT DELS SERVEIS =====

Total: 230
Running: 95
Not running: 135
```

### Resolució

He provat `Get-Service` i he mirat la propietat `Status`. Després he fet dos filtres: un amb els serveis que estan en execució i un altre amb tots els que tenen un estat diferent de `Running`.

**Proves a la consola:**

```powershell
Get-Service | Select-Object -First 5 Name, Status
$serveis = @(Get-Service)
$serveis.Count
@($serveis | Where-Object { $_.Status -eq 'Running' }).Count
@($serveis | Where-Object { $_.Status -ne 'Running' }).Count
```

**Sortida obtinguda:**

```text
Name             Status
----             ------
AarSvc_3b19ce83 Stopped
ADPSvc          Stopped
ALG             Stopped
AppIDSvc        Stopped
Appinfo         Running
314
144
170
```

**Script final:** [estatServeis.ps1](./estatServeis.ps1)

```powershell
#requires -Version 7.0

$serveis = @(Get-Service)
$serveisEnExecucio = @($serveis | Where-Object { $_.Status -eq 'Running' })
$serveisNoExecutats = @($serveis | Where-Object { $_.Status -ne 'Running' })

Write-Output '===== ESTAT DELS SERVEIS ====='
Write-Output ''
Write-Output "Total: $($serveis.Count)"
Write-Output "Running: $($serveisEnExecucio.Count)"
Write-Output "Not running: $($serveisNoExecutats.Count)"
```

**Execució del script complet:**

```powershell
pwsh -NoProfile -File .\estatServeis.ps1
```

**Sortida obtinguda:**

```text
===== ESTAT DELS SERVEIS =====

Total: 314
Running: 144
Not running: 170
```

He fet els dos recomptes sobre la mateixa llista de serveis. He comprovat que `Running` més `Not running` dona el total. Amb `-ne` també compto els estats diferents de `Running`, encara que no siguin `Stopped`.

# 3. Processos amb més consum de CPU

Crea:

```
topProcessos.ps1
```

El script ha de mostrar els **10 processos amb més consum de CPU**.

La sortida ha de mostrar únicament:

```
Name
Id
CPU
```

Després mostra també:

```

```

### Resolució

Primer he comprovat les propietats `Name`, `Id` i `CPU` dels processos. Després els he ordenat de més a menys CPU i he limitat el resultat a deu processos.

**Proves a la consola:**

```powershell
Get-Process | Select-Object -First 5 Name, Id, CPU
Get-Process | Sort-Object CPU -Descending | Select-Object -First 3 Name, Id, CPU
```

**Sortida obtinguda:**


**Script final:** [topProcessos.ps1](./topProcessos.ps1)

```powershell
#requires -Version 7.0

$processos = @(Get-Process)

    Sort-Object CPU -Descending |
    Select-Object -First 10 Name, Id, CPU |
    Format-Table -AutoSize
```

# 4. Anàlisi de fitxers d'una carpeta

Crea:

```
analitzaCarpeta.ps1
```

El script ha de treballar amb la carpeta des d'on s'executa.

Ha de mostrar:

- nombre total d'elements;

- els cinc fitxers més grans;

- nom i mida d'aquests fitxers.


Investiga les propietats retornades per:

```
Get-ChildItem
```

i utilitza-les per construir el pipeline.

> Tingues en compte que pots trobar tant fitxers com carpetes.

### Resolució

He consultat les propietats amb `Get-Member` i he provat `Name`, `Length` i `PSIsContainer`. La propietat `PSIsContainer` em permet separar les carpetes dels fitxers abans d'ordenar per mida.

**Proves a la consola:**

```powershell
Get-ChildItem -Force | Get-Member -Name Name, Length, PSIsContainer
```

**Sortida obtinguda:**

```text
TypeName: System.IO.DirectoryInfo

Name          MemberType   Definition
----          ----------   ----------
Name          Property     string Name {get;}
PSIsContainer NoteProperty bool PSIsContainer=True

   TypeName: System.IO.FileInfo

Name          MemberType   Definition
----          ----------   ----------
Name          Property     string Name {get;}
Length        Property     long Length {get;}
PSIsContainer NoteProperty bool PSIsContainer=False
```

```powershell
Get-ChildItem -Force | Select-Object Name, PSIsContainer, Length
```

**Sortida obtinguda:**

```text
Name             PSIsContainer Length
----             ------------- ------
IMG                       True
08.Scripts.md            False 9568
estatServeis.ps1         False 415
infoSistema.ps1          False 540
topProcessos.ps1         False 234
```

**Script final:** [analitzaCarpeta.ps1](./analitzaCarpeta.ps1)

```powershell
#requires -Version 7.0

# Consulto la carpeta actual, sense entrar a les subcarpetes.
$elements = @(Get-ChildItem -Force)
$fitxers = @($elements | Where-Object { -not $_.PSIsContainer })

Write-Output '===== ANÀLISI DE LA CARPETA ====='
Write-Output "Carpeta: $((Get-Location).Path)"
Write-Output "Nombre total d'elements: $($elements.Count)"
Write-Output ''
Write-Output 'Cinc fitxers més grans (Length en bytes):'

if ($fitxers.Count -gt 0) {
    $fitxers |
        Sort-Object Length -Descending |
        Select-Object -First 5 Name, Length |
        Format-Table -AutoSize
} else {
    Write-Output 'No hi ha fitxers en aquesta carpeta.'
}
```

**Execució del script complet:**

```powershell
pwsh -NoProfile -File .\analitzaCarpeta.ps1
```

**Sortida obtinguda:**

```text
===== ANÀLISI DE LA CARPETA =====
Carpeta: C:\Users\01cas\ASIX-ASO\Powershell\08.Scripts
Nombre total d'elements: 6

Cinc fitxers més grans (Length en bytes):

Name                Length
----                ------
08.Scripts.md         9568
analitzaCarpeta.ps1    647
infoSistema.ps1        540
estatServeis.ps1       415
topProcessos.ps1       234
```

El total inclou els fitxers i les carpetes del directori actual. Amb `-Force` també hi incloc els elements ocults. Per mostrar els més grans només utilitzo fitxers, perquè les carpetes no tenen una mida de fitxer a `Length`. La mida surt en bytes. Si hi ha menys de cinc fitxers, mostra els que hi ha, i si no n'hi ha cap mostra un missatge.

També l'he provat en una carpeta buida i en una altra amb sis fitxers de mides diferents i una subcarpeta. He comprovat que ordena bé els fitxers i que no entra a la subcarpeta.

# 5. Diagnosi bàsica del sistema

Crea:

```
diagnosi.ps1
```
Ha de mostrar almenys quatre apartats.

## Processos

Mostra els cinc processos amb més CPU.

Propietats:

```
Name
Id
CPU
```

## Serveis

Mostra:

```
Total de serveis
Serveis en execució
Serveis no executats
```
## Fitxers

Mostra els tres fitxers més grans de la carpeta actual.

Propietats:

```
Name
Length
```

## Estat final

Al final mostra un petit resum:

```
===== RESUM =====

Processos analitzats: ...
Serveis analitzats: ...
Fitxers analitzats: ...
```

Organitza el script perquè sigui fàcil de llegir.

Pots utilitzar comentaris per separar els diferents blocs:

```
# =====================
# PROCESSOS
# =====================
```

### Resolució

He provat per separat el filtre de processos, el recompte dels serveis i el filtre de fitxers. Després he ajuntat aquestes parts en un sol script i les he separat amb comentaris i títols.

**Proves a la consola:**

```powershell
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU
$serveis = @(Get-Service)
"Serveis: $($serveis.Count)"
"En execució: $(@($serveis | Where-Object { $_.Status -eq 'Running' }).Count)"
"No executats: $(@($serveis | Where-Object { $_.Status -ne 'Running' }).Count)"
Get-ChildItem -Force -File | Sort-Object Length -Descending | Select-Object -First 3 Name, Length | Format-Table -AutoSize
```

**Sortida obtinguda:**

```text

firefox       9256 1092,91
ChatGPT      31824  803,00
```

**Script final:** [diagnosi.ps1](./diagnosi.ps1)

```powershell
#requires -Version 7.0

# =====================
# PROCESSOS
# =====================
$processos = @(Get-Process)
Write-Output '===== PROCESSOS ====='
$processos |
    Sort-Object CPU -Descending |
    Select-Object -First 5 Name, Id, CPU |
    Format-Table -AutoSize

# =====================
# SERVEIS
# =====================
$serveis = @(Get-Service)
$serveisEnExecucio = @($serveis | Where-Object { $_.Status -eq 'Running' })
$serveisNoExecutats = @($serveis | Where-Object { $_.Status -ne 'Running' })
Write-Output '===== SERVEIS ====='
Write-Output "Total de serveis: $($serveis.Count)"
Write-Output "Serveis en execució: $($serveisEnExecucio.Count)"
Write-Output "Serveis no executats: $($serveisNoExecutats.Count)"
Write-Output ''

# =====================
# FITXERS
# =====================
$fitxers = @(Get-ChildItem -Force -File)
Write-Output '===== FITXERS ====='
Write-Output 'Tres fitxers més grans (Length en bytes):'
if ($fitxers.Count -gt 0) {
    $fitxers |
        Sort-Object Length -Descending |
        Select-Object -First 3 Name, Length |
        Format-Table -AutoSize
} else {
    Write-Output 'No hi ha fitxers en aquesta carpeta.'
}

# =====================
# RESUM
# =====================
Write-Output '===== RESUM ====='
Write-Output ''
Write-Output "Processos analitzats: $($processos.Count)"
Write-Output "Serveis analitzats: $($serveis.Count)"
Write-Output "Fitxers analitzats: $($fitxers.Count)"
```

**Execució del script complet:**

```powershell

```

**Sortida obtinguda:**


He separat la diagnosi en processos, serveis, fitxers i resum. Al resum compto tots els processos, serveis i fitxers consultats, encara que les taules només mostrin els primers cinc processos i els tres fitxers més grans. La consulta de fitxers es fa a la carpeta actual i no entra a les subcarpetes.

També l'he provat en una carpeta buida i en una altra amb sis fitxers de mides diferents i una subcarpeta. He comprovat que ordena bé els fitxers i que no entra a la subcarpeta.

# Requisits generals

Tots els scripts han de:

1. tenir extensió `.ps1`;
    
2. executar-se amb PowerShell 7;
    
3. utilitzar noms de variables descriptius;
    
4. tenir el codi correctament indentat;
    
5. incloure algun comentari quan sigui necessari;
    
6. evitar codi que no sigui necessari;
    
7. mostrar una sortida comprensible per a l'usuari.
    

Abans de donar un script per acabat:

```
prova cada part a la consola
        ↓
comprova el resultat
        ↓
incorpora-la al script
        ↓
executa el script complet
```
