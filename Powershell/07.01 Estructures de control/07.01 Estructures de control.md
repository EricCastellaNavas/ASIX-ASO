# Pràctica

## 1. Condicional

Crea:
```powershell
$port = 443
```
Mostra:
```
Port HTTPS
```
si el port és `443`.

Canvia després el valor de `$port` i comprova què passa.

### Resolució

Primer he provat el port 443 i després he canviat el valor a 80.

**Port 443:**

```powershell
$port = 443
if ($port -eq 443) {
    "Port HTTPS"
}
```

**Sortida obtinguda:**

```text
Port HTTPS
```

**Canvio el port:**

```powershell
$port = 80
if ($port -eq 443) {
    "Port HTTPS"
}
```

**Resultat:** no mostra cap missatge.

Amb el port 443 surt `Port HTTPS`. Quan poso 80 no surt cap missatge perquè la condició és falsa i no he posat cap `else`.

## 2. if o switch

Crea:
```
$estat = 2
```
Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

### Resolució

He fet una funció amb `if` i una altra amb `switch` per poder provar els mateixos estats amb les dues solucions.

**Solució amb if:**

```powershell
function Mostrar-EstatIf {
    param($estat)
    if ($estat -eq 1) {
        "Iniciant"
    } elseif ($estat -eq 2) {
        "Executant"
    } elseif ($estat -eq 3) {
        "Finalitzat"
    } elseif ($estat -eq 4) {
        "En espera"
    } else {
        "Estat desconegut"
    }
}
$estat = 2
Mostrar-EstatIf $estat
```

**Sortida obtinguda:**

```text
Executant
```

**Solució amb switch:**

```powershell
function Mostrar-EstatSwitch {
    param($estat)
    switch ($estat) {
        1 { "Iniciant" }
        2 { "Executant" }
        3 { "Finalitzat" }
        4 { "En espera" }
        default { "Estat desconegut" }
    }
}
$estat = 2
Mostrar-EstatSwitch $estat
```

**Sortida obtinguda:**

```text
Executant
```

**Provo tots els casos:**

```powershell
foreach ($estat in 1, 2, 3, 4, 9) {
    [PSCustomObject]@{
        Estat = $estat
        If = Mostrar-EstatIf $estat
        Switch = Mostrar-EstatSwitch $estat
    }
}
```

**Sortida obtinguda:**

```text
Estat If               Switch
----- --               ------
    1 Iniciant         Iniciant
    2 Executant        Executant
    3 Finalitzat       Finalitzat
    4 En espera        En espera
    9 Estat desconegut Estat desconegut
```

Les dues solucions donen el mateix resultat. En aquest cas em sembla més fàcil de llegir el `switch`, perquè comparo una variable amb diversos valors concrets. Amb `if` i `elseif` també ho puc fer, però he de repetir la comparació a cada condició. El `else` i el `default` serveixen per mostrar `Estat desconegut` quan el valor no coincideix amb cap dels quatre estats.

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```
Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu

### Resolució

He unit les dues condicions amb `-and`, perquè s'han de complir totes dues.

**Port correcte i servei actiu:**

```powershell
$port = 443
$actiu = $true
if (($port -eq 443) -and $actiu) {
    "Servei disponible"
}
```

**Sortida obtinguda:**

```text
Servei disponible
```

**Port diferent i servei actiu:**

```powershell
$port = 80
$actiu = $true
if (($port -eq 443) -and $actiu) {
    "Servei disponible"
}
```

**Resultat:** no mostra cap missatge.

**Port correcte i servei inactiu:**

```powershell
$port = 443
$actiu = $false
if (($port -eq 443) -and $actiu) {
    "Servei disponible"
}
```

**Resultat:** no mostra cap missatge.

El missatge només surt amb el port 443 i `$actiu` a `$true`. Si falla una de les dues condicions, no mostra res. `-eq` compara el port i `-and` comprova que es compleixin les dues condicions alhora.

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip?

Proposa diferents codis de resolució.

### Resolució

He guardat els serveis en una variable i he fet tres recomptes sobre la mateixa llista per comparar els resultats.

**Filtro amb Where-Object:**

```powershell
$serveis = Get-Service
$automatics = @($serveis | Where-Object { $_.StartType -eq 'Automatic' })
$automatics.Count
```

**Sortida obtinguda:**

```text
97
```

**Compto amb foreach i if:**

```powershell
$comptador = 0
foreach ($servei in $serveis) {
    if ($servei.StartType -eq 'Automatic') {
        $comptador++
    }
}
$comptador
```

**Sortida obtinguda:**

```text
97
```

**Compto amb Measure-Object:**

```powershell
($serveis | Where-Object { $_.StartType -eq 'Automatic' } | Measure-Object).Count
```

**Sortida obtinguda:**

```text
97
```

**Mostro alguns serveis trobats:**

```powershell
$automatics | Select-Object -First 8 Name, StartType, Status
```

**Sortida obtinguda:**

```text
Name                 StartType  Status
----                 ---------  ------
AppXSvc              Automatic Running
AudioEndpointBuilder Automatic Running
Audiosrv             Automatic Running
BFE                  Automatic Running
BrokerInfrastructure Automatic Running
camsvc               Automatic Running
cbdhsvc_3b19ce83     Automatic Running
CDPSvc               Automatic Running
```

Els tres mètodes em donen **97 serveis** configurats amb arrencada automàtica en el moment de fer la pràctica. He filtrat per `StartType`, que indica el tipus d'arrencada. No he filtrat per `Status`, perquè un servei automàtic pot estar aturat en aquest moment i un servei en execució pot tenir arrencada manual. Amb `foreach` he de portar el comptador; amb `Where-Object` i `Measure-Object` el codi queda més curt.

# Conclusions

Explica amb les teves paraules:

1. Què representa la variable `$servei` en:
```powershell
$serveis = Get-Service
foreach ($servei in $serveis) {
    ...
}
```
2. Quina diferència hi ha entre `foreach` i `ForEach-Object`?
3. Què representa `$_` dins de `ForEach-Object`?

### Resolució

1. **La variable `$servei`:** representa el servei que estic tractant en aquella volta del bucle. `$serveis` conté la llista i `$servei` és un objecte d'aquesta llista. Puc consultar-ne les propietats, com `$servei.Name`, `$servei.Status` o `$servei.StartType`.

2. **`foreach` i `ForEach-Object`:** amb `foreach ($servei in $serveis)` recorro una col·lecció i dono un nom a la variable de cada element. `ForEach-Object` és una ordre que rep els objectes pel pipeline i executa el bloc per cada objecte que li arriba. Per exemple, puc escriure `$serveis | ForEach-Object { $_.Name }` per mostrar els noms dels serveis.

3. **`$_` dins de `ForEach-Object`:** és l'objecte que s'està processant en aquell moment. Si pel pipeline arriben serveis, `$_` és el servei actual i `$_.Name` és el seu nom. En l'exemple anterior fa el mateix paper que `$servei` dins del `foreach`.
