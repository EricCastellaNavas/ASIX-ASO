# Pràctica

## 1. Condicional

Crea:
```powershell
$port = 443
```
Mostra:
```
Port HTTPS
```
si el port és `443`.

Canvia després el valor de `$port` i comprova què passa.

### Resolució

Primer he provat el port 443 i després he canviat el valor a 80.

**Port 443:**

```powershell
$port = 443
if ($port -eq 443) {
    "Port HTTPS"
}
```

**Sortida obtinguda:**

```text
Port HTTPS
```

**Canvio el port:**

```powershell
$port = 80
if ($port -eq 443) {
    "Port HTTPS"
}
```

**Resultat:** no mostra cap missatge.

Amb el port 443 surt `Port HTTPS`. Quan poso 80 no surt cap missatge perquè la condició és falsa i no he posat cap `else`.
