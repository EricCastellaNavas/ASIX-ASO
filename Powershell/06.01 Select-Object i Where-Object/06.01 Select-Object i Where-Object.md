## 4. Primer filtre

Crea:

```
$numeros = 5, 20, 3, 40, 12, 8, 30
```

Utilitzant `Where-Object`, mostra (adjunta comandes):

1. els números superiors a `10`;

2. els números inferiors a `20`;

3. els números iguals a `12`;

4. tots els números diferents de `20`.

Per cada cas identifica quin operador has utilitzat:

```
-eq
-ne
-gt
-lt
-ge
-le
```

### Resolució

He utilitzat la mateixa variable com a origen dels quatre filtres.

**Superiors a 10:**

```powershell
$numeros = 5, 20, 3, 40, 12, 8, 30
$numeros | Where-Object { $_ -gt 10 }
```

**Sortida obtinguda:**

```text
20
40
12
30
```

**Inferiors a 20:**

```powershell
$numeros | Where-Object { $_ -lt 20 }
```

**Sortida obtinguda:**

```text
5
3
12
8
```

**Iguals a 12:**

```powershell
$numeros | Where-Object { $_ -eq 12 }
```

**Sortida obtinguda:**

```text
12
```

**Diferents de 20:**

```powershell
$numeros | Where-Object { $_ -ne 20 }
```

**Sortida obtinguda:**

```text
5
3
40
12
8
30
```

| Condició | Operador utilitzat |
|---|---|
| Superior a 10 | `-gt` |
| Inferior a 20 | `-lt` |
| Igual a 12 | `-eq` |
| Diferent de 20 | `-ne` |

`-ge` significa major o igual, i `-le` significa menor o igual. A diferència de `-gt` i `-lt`, inclouen el valor del límit.

El filtre conserva l'ordre dels elements que compleixen la condició; no els ordena.

## 5. Entendre `$_`

Utilitza:

```
$numeros = 5, 20, 3
```

i analitza:

```
$numeros |
    Where-Object { $_ -gt 10 }
```

Completa:

|Valor de `$_`|Resultat de `$_ -gt 10`|Passa el filtre?|
|---|---|---|
|5|`False`|No|
|20|`True`|Sí|
|3|`False`|No|

Explica amb les teves paraules:

**Què representa** `$_`**?**

### Resolució

He executat el filtre i després he comprovat les tres comparacions per emplenar la taula.

**Resultat del filtre:**

```powershell
$numeros = 5, 20, 3
$numeros |
    Where-Object { $_ -gt 10 }
```

**Sortida obtinguda:**

```text
20
```

**Resultat de cada comparació:**

```powershell
5 -gt 10
20 -gt 10
3 -gt 10
```

**Sortida obtinguda:**

```text
False
True
False
```

`$_` representa l'objecte que s'està avaluant en aquell moment. Primer val `5`, després `20` i finalment `3`; no representa tot l'array alhora.

Només `20` fa que la condició retorni `True`, i és l'únic valor que passa el filtre.

## 7. Combinar condicions

Crea:

```
$numeros = 1, 5, 10, 15, 20, 25, 30, 40
```

Construeix filtres que mostrin:

1. números entre `10` i `30` ambdós inclosos;

2. números inferiors a `10` o superiors a `30`.

### Resolució

He comprovat un interval amb els dos límits inclosos i un filtre que selecciona els valors de fora de l'interval.

**Entre 10 i 30, inclosos:**

```powershell
$numeros = 1, 5, 10, 15, 20, 25, 30, 40
$numeros | Where-Object { $_ -ge 10 -and $_ -le 30 }
```

**Sortida obtinguda:**

```text
10
15
20
25
30
```

**Inferiors a 10 o superiors a 30:**

```powershell
$numeros | Where-Object { $_ -lt 10 -or $_ -gt 30 }
```

**Sortida obtinguda:**

```text
1
5
40
```

Amb `-and` s'han de complir les dues condicions: el resultat és `10, 15, 20, 25, 30`. `-ge` i `-le` inclouen els límits.

Amb `-or` n'hi ha prou que es compleixi una condició: el segon filtre retorna `1, 5, 40`.
