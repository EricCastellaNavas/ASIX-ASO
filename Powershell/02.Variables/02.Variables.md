# Treballar amb variables

## 1. Crear variables

Crea les variables següents:

```
$nom
$servidor
$ip
$port
```

Assigna-hi valors.

Per exemple:

```
$nom = "Pere"
```

Mostra després el contingut de cadascuna de les variables.

### Resolució

He assignat valors d'exemple a les quatre variables. Després he escrit el nom de cada variable per mostrar-ne el contingut.

```powershell
$nom = "Eric"
$servidor = "SRV01"
$ip = "192.168.1.10"
$port = 443

$nom
$servidor
$ip
$port
```

**Sortida obtinguda:**

```text
Eric
SRV01
192.168.1.10
443
```

Les assignacions guarden els valors. En escriure `$nom`, `$servidor`, `$ip` i `$port`, PowerShell mostra el valor que conté cadascuna. La IP d'aquest exercici és un valor d'exemple assignat a una variable.

---

## 2. Modificar una variable

Crea:

```
$servidor = "SRV01"
```

Mostra el seu valor.

Després canvia'l per:

```
SRV02
```

Comprova quin valor conserva la variable.

### Resolució

He creat `$servidor`, he mostrat el primer valor i després l'he substituït.

```powershell
$servidor = "SRV01"
$servidor

$servidor = "SRV02"
$servidor
```

**Sortida obtinguda:**

```text
SRV01
SRV02
```

La primera consulta retorna `SRV01` i la segona retorna `SRV02`. La variable conserva l'últim valor assignat: la nova assignació substitueix l'anterior.

---

## 3. Operacions

Crea dues variables:

```
$num1 = 20
$num2 = 5
```

Crea una tercera variable que guardi:

- la suma;
- la resta;
- la multiplicació;
- la divisió.

Per exemple:

```
$resultat = $num1 + $num2
```

Mostra cada resultat.

### Resolució

He utilitzat les mateixes dues variables i he guardat cada operació a `$resultat` abans de mostrar-la.

```powershell
$num1 = 20
$num2 = 5

$resultat = $num1 + $num2
$resultat

$resultat = $num1 - $num2
$resultat

$resultat = $num1 * $num2
$resultat

$resultat = $num1 / $num2
$resultat
```

**Sortida obtinguda:**

```text
25
15
100
4
```

| Operació | Expressió | Resultat |
|---|---|---|
| Suma | `$num1 + $num2` | `25` |
| Resta | `$num1 - $num2` | `15` |
| Multiplicació | `$num1 * $num2` | `100` |
| Divisió | `$num1 / $num2` | `4` |

`$resultat` canvia amb cada assignació i, al final, conserva `4`, el resultat de l'última operació.

## 4. Variables dins d'un text

Crea:

```
$nom = "Anna"
$servidor = "SRV01"
```

Intenta obtenir aquesta sortida:

```
L'usuari Anna està treballant amb el servidor SRV01
```

utilitzant les variables dins del text.

### Resolució

He escrit el text entre cometes dobles perquè PowerShell substitueixi les variables pels seus valors.

```powershell
$nom = "Anna"
$servidor = "SRV01"

"L'usuari $nom està treballant amb el servidor $servidor"
```

**Sortida obtinguda:**

```text
L'usuari Anna està treballant amb el servidor SRV01
```

La sortida coincideix amb la frase demanada. Les cometes dobles permeten incloure els valors de `$nom` i `$servidor` dins de la cadena de text.

## 5. Cometes

Executa:

```
$servidor = "SRV01"
```

Després:

```
Write-Host "Servidor: $servidor"
```

i:

```
Write-Host 'Servidor: $servidor'
```

Respon:

**Quina diferència observes? Per què creus que passa?**

### Resolució

He executat les dues ordres amb el mateix valor de `$servidor`.

```powershell
$servidor = "SRV01"

Write-Host "Servidor: $servidor"
Write-Host 'Servidor: $servidor'
```

**Sortida obtinguda:**

```text
Servidor: SRV01
Servidor: $servidor
```

**Diferència observada:** amb cometes dobles surt `Servidor: SRV01`. Amb cometes simples surt literalment `Servidor: $servidor`.

Això passa perquè les cometes dobles permeten expandir les variables. Les cometes simples tracten el contingut com un text literal i no substitueixen `$servidor` pel seu valor.

**Què conté `$serveis`?** Conté els objectes dels serveis que ha retornat `Get-Service`. Cadascun té propietats com `Name`, `DisplayName` i `Status`; el tipus del primer element es mostra amb `.GetType().FullName`.

**Un valor o diversos elements?** La variable conté diversos elements, com confirma `$serveis.Count`. No és només el text de la taula: podem consultar les propietats de cada servei.

**Què passa amb `$processos`?** També conté diversos objectes, en aquest cas de tipus `System.Diagnostics.Process`. Podem consultar-ne propietats com `Id`, `ProcessName` i `CPU`. `$processos.Count` indica quants objectes s'han guardat. El nombre de serveis, processos i els seus estats poden variar entre execucions.

Get-Service -Name Spooler

però **sense escriure `Spooler` directament en el cmdlet**.

### Resolució

He utilitzat `$nomServei` com a valor del paràmetre `-Name`.

**Consulta utilitzant la variable:**

```powershell
$nomServei = "Spooler"
Get-Service -Name $nomServei
```

**Sortida obtinguda:**

```text
Status   Name               DisplayName
------   ----               -----------
Running  Spooler            Cola de impresión
```

**Consulta directa per comparar:**

```powershell
Get-Service -Name Spooler
```

**Sortida obtinguda:**

```text
Status   Name               DisplayName
------   ----               -----------
Running  Spooler            Cola de impresión
```

Les dues consultes retornen el servei `Spooler`. A la primera, el cmdlet no conté el text `Spooler` directament: rep el nom a través de `$nomServei`.

Això permet reutilitzar la mateixa ordre per consultar un altre servei canviant només el valor de la variable.
