# Tipus de dades

## 1. Identificar tipus

Crea les variables següents:
```powershell
$nom = "Servidor01"
$port = 443
$actiu = $true
$espai = 12.5
```
Consulta el tipus de cadascuna amb:
```powershell
.GetType()
```
Completa una taula com aquesta:

| Variable | Valor        | Tipus |
| -------- | ------------ | ----- |
| `$nom` | `Servidor01` | `System.String` |
| `$port` | `443` | `System.Int32` |
| `$actiu` | `$true` | `System.Boolean` |
| `$espai` | `12.5` | `System.Double` |

### Resolució

He creat les quatre variables i he consultat el tipus de cadascuna amb `.GetType()`.

```powershell
$nom = "Servidor01"
$port = 443
$actiu = $true
$espai = 12.5

$nom.GetType()
$port.GetType()
$actiu.GetType()
$espai.GetType()
```

**Sortida obtinguda:**

```text
IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     String                                   System.Object
True     True     Int32                                    System.ValueType
True     True     Boolean                                  System.ValueType
True     True     Double                                   System.ValueType
```

La columna `Name` de la sortida indica el tipus: `String` per al text, `Int32` per a l'enter, `Boolean` per al valor lògic i `Double` per al decimal. Com que no he escrit un tipus davant de les variables, PowerShell l'ha determinat a partir del valor assignat.

## 2. Número o text?

Executa:
```powershell
$a = 10
$b = 5

$a + $b
```
Després:
```powershell
$a = "10"
$b = "5"

$a + $b
```
Respon:

- Quin resultat obtens en cada cas?
- Per què no és el mateix?
Mostra després el contingut de cadascuna de les variables.


- Quin tipus tenen $a i $b en cada cas?

### Resolució

He comparat les dues sumes i, en cada cas, he mostrat els valors i els tipus de `$a` i `$b`.

**Suma de nombres:**

```powershell
$a = 10
$b = 5
$a + $b
```

**Sortida obtinguda:**

```text
15
```

**Valors i tipus del primer cas:**

```powershell
$a
$b
$a.GetType().FullName
$b.GetType().FullName
```

**Sortida obtinguda:**

```text
10
5
System.Int32
System.Int32
```

**Suma de textos:**

```powershell
$a = "10"
$b = "5"
$a + $b
```

**Sortida obtinguda:**

```text
105
```

**Valors i tipus del segon cas:**

```powershell
$a
$b
$a.GetType().FullName
$b.GetType().FullName
```

**Sortida obtinguda:**

```text
10
5
System.String
System.String
```

| Cas | Resultat de `$a + $b` | Tipus de `$a` | Tipus de `$b` |
|---|---|---|---|
| `10` i `5`, sense cometes | `15` | `System.Int32` | `System.Int32` |
| `"10"` i `"5"`, entre cometes | `105` | `System.String` | `System.String` |

En el primer cas, `+` fa una suma numèrica. En el segon, uneix les dues cadenes de text: això és concatenar. Tot i que els valors es veuen com `10` i `5` en mostrar-los, el seu tipus determina el comportament de l'operador.

## 3. Canviar el tipus d'una variable

Executa:
```powershell
$valor = 100
```
Consulta:
```powershell
$valor.GetType()
```
Ara executa:
```powershell
$valor = "100"
```
i torna a consultar:
```powershell
$valor.GetType()
```
Respon:

**Ha canviat el valor? Ha canviat el tipus?**

### Resolució

He mostrat el valor i el tipus abans i després de tornar a assignar la variable.

**Primera assignació:**

```powershell
$valor = 100
$valor
$valor.GetType()
```

**Sortida obtinguda:**

```text
100

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     Int32                                    System.ValueType
```

**Segona assignació:**

```powershell
$valor = "100"
$valor
$valor.GetType()
```

**Sortida obtinguda:**

```text
100

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     String                                   System.Object
```

**Ha canviat el valor? Ha canviat el tipus?** La representació visible continua sent `100`, però abans era un nombre enter i després és una cadena de text. El tipus canvia de `System.Int32` a `System.String`.

Com que `$valor` no té un tipus explícit, en aquesta prova pot guardar primer un enter i després text.

## 4. Tipus explícits

Executa:
```powershell
[int]$port = 443
```
Comprova el tipus:
```powershell
$port.GetType()
```
Ara prova:
```
[string]$portText = 443
```
Consulta també:
```powershell
$portText.GetType()
```
Respon:

**Tot i que visualment els dos valors semblen `443`, són del mateix tipus?**

### Resolució

He declarat una variable com a enter i una altra com a text. He mostrat els seus valors i he consultat els tipus.

**Variable de tipus enter:**

```powershell
[int]$port = 443
$port
$port.GetType()
```

**Sortida obtinguda:**

```text
443

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     Int32                                    System.ValueType
```

**Variable de tipus text:**

```powershell
[string]$portText = 443
$portText
$portText.GetType()
```

**Sortida obtinguda:**

```text
443

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     String                                   System.Object
```

**Són del mateix tipus?** No. `$port` és `System.Int32` i `$portText` és `System.String`, encara que tots dos mostrin `443`.

`[int]` declara el tipus enter. `[string]` declara el tipus text i converteix el valor assignat en una cadena.

## 5. Booleans

Crea:
```powershell
$serveiActiu = $true
$servidorDisponible = $false
```
Consulta els tipus.

Després mostra un missatge amb:
```
Write-Host "Servei actiu: $serveiActiu"
Write-Host "Servidor disponible: $servidorDisponible"
```

### Resolució

He creat les dues variables lògiques, n'he consultat els tipus i després les he inclòs als missatges.

**Creació i consulta dels tipus:**

```powershell
$serveiActiu = $true
$servidorDisponible = $false

$serveiActiu.GetType()
$servidorDisponible.GetType()
```

**Sortida obtinguda:**

```text
IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     Boolean                                  System.ValueType
True     True     Boolean                                  System.ValueType
```

**Missatges:**

```powershell
Write-Host "Servei actiu: $serveiActiu"
Write-Host "Servidor disponible: $servidorDisponible"
```

**Sortida obtinguda:**

```text
Servei actiu: True
Servidor disponible: False
```

Les dues variables són de tipus `System.Boolean`. `$true` representa cert i `$false` representa fals. Quan PowerShell les mostra dins del text, apareixen com `True` i `False`.
