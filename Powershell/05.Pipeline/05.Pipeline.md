He fet les proves amb PowerShell 7.6.5 sobre Windows. Les sortides de processos i serveis corresponen al moment de cada consulta. La propietat CPU indica temps de processador acumulat en segons, no un percentatge instantani.

## 3. Construir un pipeline pas a pas

Executa primer:

```powershell
Get-Process
```

Ara:

```powershell
Get-Process | Sort-Object CPU
```

Finalment:

```powershell
Get-Process |
    Sort-Object CPU |
    Select-Object -First 5
```

No continuïs fins haver observat el resultat de cada ordre.

Completa:

| Pas | Ordre | Què entra? | Què surt? |
|---|---|---|---|
| 1 | `Get-Process` | No rep dades del pipeline; consulta els processos del sistema. | Objectes amb informació dels processos en execució. |
| 2 | `Sort-Object CPU` | Els objectes retornats per `Get-Process`. | Els mateixos processos ordenats pel valor de CPU, de menor a major. |
| 3 | `Select-Object -First 5` | Els processos ordenats. | Els cinc primers processos de la llista ordenada. |

Explica què passaria si eliminéssim:

```powershell
Sort-Object CPU
```

## 5. Canviar l'ordre del pipeline

```powershell
Get-Process |
    Sort-Object CPU -Descending |
    Select-Object -First 5
```

```powershell
Get-Process |
    Select-Object -First 5 |
```

## 12. Separar un pipeline en passos

Tenim:

```powershell
Get-Process |
    Sort-Object CPU -Descending |
    Select-Object -First 5
```

Reescriu-lo sense utilitzar un pipeline de tres ordres.

Utilitza variables intermèdies.

La idea hauria de ser:

```text
obtenir processos
↓
guardar-los
↓
ordenar-los
↓
guardar el resultat
↓
seleccionar-ne cinc
```

Comprova que el resultat final sigui equivalent.

Després explica:

**Quin avantatge té utilitzar el pipeline respecte d'anar creant variables intermèdies?**

### Resolució

He guardat una instantània de les propietats `Id`, `ProcessName` i `CPU` per comparar les dues formes amb les mateixes dades.

**Variables intermèdies:**

```powershell
$processos = Get-Process | Select-Object Id,ProcessName,CPU
$ordenats = $processos | Sort-Object CPU -Descending
$cincPrimers = $ordenats | Select-Object -First 5
$cincPrimers
```

**Sortida obtinguda:**

```text
Id ProcessName     CPU
   -- -----------     ---
 4292 firefox     1283,95
 9256 firefox      897,81
27416 firefox      677,69
24556 firefox      459,77
11172 wallpaper32  262,59
```

**Forma equivalent:**

```powershell
$ambPipeline = $processos |
    Sort-Object CPU -Descending |
    Select-Object -First 5
$ambPipeline
```

**Sortida obtinguda:**

```text
Id ProcessName     CPU
   -- -----------     ---
 4292 firefox     1283,95
 9256 firefox      897,81
27416 firefox      677,69
24556 firefox      459,77
11172 wallpaper32  262,59
```

**Comparació dels identificadors:**

```powershell
@(Compare-Object -ReferenceObject @($cincPrimers.Id) -DifferenceObject @($ambPipeline.Id)).Count -eq 0
```

**Sortida obtinguda:**

```text
True
```

La primera resolució separa l'obtenció, l'ordenació i la selecció en variables. Cada pipeline d'aquesta forma té com a màxim dues ordres. La comprovació compara els identificadors dels cinc processos: `True` indica que les dues formes coincideixen.

El pipeline evita crear variables per a tots els resultats intermedis i expressa el recorregut en una instrucció. Les variables intermèdies permeten inspeccionar o reutilitzar cada etapa.
