## 12. Separar un pipeline en passos

PowerShell 7.6.5 | 2026-10-19 15:52:04 +02:00


Variables intermèdies
PS> $processos = Get-Process | Select-Object Id,ProcessName,CPU
$ordenats = $processos | Sort-Object CPU -Descending
$cincPrimers = $ordenats | Select-Object -First 5
$cincPrimers
Id ProcessName     CPU
   -- -----------     ---
 4292 firefox     1283,95
 9256 firefox      897,81
27416 firefox      677,69
24556 firefox      459,77
11172 wallpaper32  262,59


Forma equivalent
PS> $ambPipeline = $processos |
    Sort-Object CPU -Descending |
    Select-Object -First 5
$ambPipeline
Id ProcessName     CPU
   -- -----------     ---
 4292 firefox     1283,95
 9256 firefox      897,81
27416 firefox      677,69
24556 firefox      459,77
11172 wallpaper32  262,59


Comparació dels identificadors
PS> @(Compare-Object -ReferenceObject @($cincPrimers.Id) -DifferenceObject @($ambPipeline.Id)).Count -eq 0
True
